# Plumbing work photo uploads

Add new project photos to this folder (`public/work-photos/`) in GitHub.
Use Add file -> Upload files, select photos and commit them to the
`homepage-rehab` branch while testing.

Supported: JPG, JPEG, PNG, WebP and AVIF. Photos appear automatically in the
Work Gallery after the next successful Vercel build. No code changes are needed.
Use descriptive file names such as `water-heater-installation-01.jpg`.
Compress large phone photos first to keep the page fast.

The gallery also includes existing real-job photos from
`public/plumbing-images/`. Images in the older folder with names like
`fixture1.webp` and `hero1.webp` are not included because they may be
stock or illustrative images rather than documented company projects.

This is a public photo gallery, not a private upload portal. Check that
pictures do not include customer personal information or addresses before
uploading. A future admin uploader could be added separately.
